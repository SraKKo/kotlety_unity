IMPORTANT ENGINE SETTING (Unity / Unreal):
To get the crisp, pixelated retro look, you MUST change these settings on the texture file inside your game engine:
- Filter Mode: Point (No Filter)
- Mip Maps: Disabled (Uncheck 'Generate Mip Maps')

If you skip this, the engine will blur the texture and it will look muddy.

CONTENTS:
- Models: Crates, barrels, boxes, and separate lids (.fbx)
- Textures: Everything is on a single texture atlas for better performance.
